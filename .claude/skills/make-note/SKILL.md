# 整理筆記

## 1. 確認範圍與深度

- 哪一門課、哪幾週、哪幾份講義（在課程 `講義/`）。
- 深度看 `CLAUDE.local.md` 的「筆記深度」，學生這次另有要求就照這次的。
- 先讀課程 README 的進度紀錄，知道前面教到哪。

## 2. 讀講義

- PDF：抽文字；圖多的頁面轉成圖片看。
- PPT／PPTX：轉成 PDF 再讀，轉完核對第一頁標題是不是對的那份。
- 錄音或影片：先轉逐字稿，刪掉轉錄模型最後常出現的幻覺句。
- 標出講義上的錯誤（程式編譯不過、數字算錯），之後寫在筆記裡。

## 3. 寫 HTML

從 [_templates/筆記範本.html](../../../_templates/筆記範本.html) 複製到 `<課名>/筆記/原始檔/W03-主題.html`。

**零基礎深度**的每一節：
1. 白話／比喻：這個觀念在解決什麼問題
2. 逐行解說：程式碼放左邊，白話解釋放右邊（用表格）
3. 照著做的步驟
4. 常見錯誤：附**實際**的錯誤訊息（自己故意寫錯、真的跑一次）
5. 練習題：用 `<details>` 包答案

**一般深度**：觀念卡＋重點框＋例題＋檢核題。
**精簡深度**：一頁重點、公式、易錯點。

共同規則：
- 開頭放目錄；篇幅長時標「★ 時間不夠先讀」。
- 所有程式碼與輸出**實際執行過**，貼真實輸出。
- 用腳本產生的長篇筆記，產生器存進 `筆記/原始檔/`。
- 頁尾寫來源（講義檔名、頁數）與整理日期。
- 不要把講義原文整段貼上，用自己的話重寫。

## 4. 轉 PDF

- macOS／Linux：`bash tools/note2pdf.sh "<課名>/筆記/原始檔/W03-主題.html"`
- Windows：`powershell -ExecutionPolicy Bypass -File tools\note2pdf.ps1 "<課名>\筆記\原始檔\W03-主題.html"`

看腳本印出的頁數是否合理。抽幾頁轉圖片檢查：表格有沒有被切斷、程式碼有沒有超出頁面。

## 5. 交付

把 PDF 給學生（Claude 桌面版用 SendUserFile）。在課程 README 的進度紀錄加一行：哪一週、筆記檔名、頁數。
