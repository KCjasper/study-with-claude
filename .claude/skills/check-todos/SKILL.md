# 查未交作業

## 1. 取得資料

依 `CLAUDE.local.md` 的學校平台，照 `adapters/<平台>.md` 的方法查：
- 跨課程的待辦清單
- 每門課尚未截止的作業，逐一確認自己的繳交紀錄（待辦清單常常漏列）
- 分組作業要查組的繳交紀錄，不是個人的

沒有 adapter 或瀏覽器連不上：照 `adapters/manual.md`，請學生截圖平台的待辦頁或貼上文字。

## 2. 對照工作區

- 學期 README 的截止日表：補上新項目、更新狀態（未開始／進行中／已繳交／已過期）
- 課程 `作業/` 資料夾：哪些已經開始寫

## 3. 回報

列一張表，**依截止時間排序**：

| 截止 | 課程 | 項目 | 狀態 | 預估時間 | 備註 |
|---|---|---|---|---|---|

標出：
- 24 小時內截止的
- 截止時間不是 23:59 的（例：下午 5 點、早上 10 點）
- 分組作業（誰負責上傳）
- 只開放在課堂上交的

## 4. 接下來

建議先做哪一份。學生如果同時說了要怎麼做（「全部幫我做完」或「陪我一份一份寫」），就照那個模式交給 `/homework`；沒說就問一次。
可以先做的準備：下載題目與附件到 `作業/<作業名>/`、整理會用到的觀念。

**不代為繳交**。
