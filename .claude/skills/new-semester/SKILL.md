# 建立新學期

## 1. 讀課表

學生可能給：選課系統截圖、課表 PDF、貼上的文字。讀出每門課的：課名、老師、星期、節次、教室、學分。
看不清楚或缺的欄位列出來問學生，不要猜。把原始課表檔搬進學期資料夾（例：`115-1/課表.png`）。

學期資料夾命名：`<學年>-<學期>`，台灣學校用民國學年（2026 年 9 月開始的學期是 `115-1`，2027 年 2 月是 `115-2`）。

## 2. 建資料夾

```
115-1/
├── README.md
└── <課名>/
    ├── README.md
    ├── 講義/
    ├── 作業/
    └── 筆記/原始檔/
```

課名有括號或斜線時改成檔名安全的寫法（「日文（一）」→ `日文一`），在學期 README 的課程表寫明對應。

## 3. 寫 README

- 學期 README：用 [_templates/學期README範本.md](../../../_templates/學期README範本.md)，填課表（節次 × 星期）與課程表。
- 課程 README：用 [_templates/課程README範本.md](../../../_templates/課程README範本.md)。

## 4. 補課程資訊

如果學生的平台有 adapter（見 `CLAUDE.local.md`），到每門課的課程頁、課程大綱讀：評分方式、**AI 使用規定**、作業繳交規定、考試日期，填進課程 README，日期加進學期 README 的截止日表。
沒有 adapter，就請學生把每門課第一週的課程簡介投影片或大綱放進 `講義/`，從那裡讀。

找不到 AI 規定的課，在 README 寫「未說明」，提醒學生第一週問老師。

## 5. 更新工作區 CLAUDE.local.md

把「目前學期資料夾」改成新的學期。
