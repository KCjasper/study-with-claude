## AI 使用規定

老師原話（第一週課程簡介 p.5）：「可以用 AI 查觀念、看範例、找 bug，但作業不能整份叫 AI 寫。」
→ 作業用 `/homework`。這位示範學生想把上機考練熟，所以 HW02 選了引導模式（說「陪我寫」）；選解答模式時，Claude 會先提醒一次這條規定。

## 作業繳交規定

- 截止：**週一 17:00**（不是 23:59），一律不補交。
- 檔名：`HW<兩位數次數>_<學號>_<題號>.java`，例：`HW02_410000000_01.java`。
- 上傳所有 .java 檔，不要上傳 .class 或整個專案資料夾。

## 開發環境

- JDK 21；平常用 IntelliJ IDEA，**考場是 NetBeans**，考前要用 NetBeans 練一次。
- 命令列：`javac -encoding UTF-8 TempConvert.java && java TempConvert`

## 進度紀錄

## 易錯點

- 方法頭寫 `int` 卻忘了 `return`（missing return statement）
- `main` 呼叫的方法忘了加 `static`
- 整數相除會捨去小數：`5 / 9` 是 0
