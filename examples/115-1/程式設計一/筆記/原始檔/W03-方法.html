1. ★ 方法是什麼：一台小機器

比喻：果汁機

你把水果放進去（參數），它在裡面做事（方法本體），最後吐出一杯果汁（回傳值）。你不用每次都重新組一台果汁機，只要「呼叫」它就好。

參數 3、5→add 方法→回傳 8

為什麼要用方法？同一段計算會用很多次時，寫成方法只要寫一次；而且 main 會變短、好讀，出錯時也知道去哪一塊找。

2. ★ 逐行看懂第一個方法

public class AddDemo {
    static int add(int a, int b) {
        int sum = a + b;
        return sum;
    }

    static void greet(String name) {
        System.out.println("哈囉，" + name);
    }

    public static void main(String[] args) {
        int r = add(3, 5);
        System.out.println("3 + 5 = " + r);
        System.out.println("10 + 20 = " + add(10, 20));
        greet("小明");
    }
}
程式白話
static這個方法屬於整個類別，main 可以直接叫它（現階段先記：寫在 main 旁邊的方法都加 static）
int（方法名前面）回傳值的型態：這台機器最後吐出一個整數
add方法的名字，自己取，動詞開頭、小寫開頭
(int a, int b)參數：要放進機器的兩個整數，進來後叫 a 和 b
return sum;把結果吐出去，方法到這裡結束
int r = add(3, 5);呼叫：3 放進 a、5 放進 b，吐出的 8 存進 r
add(10, 20) 直接放在 println 裡回傳值可以直接拿來用，不一定要先存進變數

執行結果：

3 + 5 = 8
10 + 20 = 30
哈囉，小明

3. 照著做：自己寫一個方法的 4 步

  1. 想清楚進出：要放進什麼（參數型態）？吐出什麼（回傳型態）？什麼都不吐就是 void。
  2. 先寫空殼：static 回傳型態 名字(參數) { }，在 main 裡先呼叫一次，確認能編譯。
  3. 填本體：在大括號裡算，最後 return。
  4. 用 2～3 組數字測：包含 0、負數這種邊界值。

4. void：不回傳東西的方法

有回傳值（int）算出一個數字交給呼叫的人，呼叫的人決定要印還是要再算
void自己把事情做完（例如印出來），不交回任何東西

greet("小明") 是 void 方法：它自己印出「哈囉，小明」，所以呼叫時單獨一行就好，不能寫在等號右邊。

5. ★ 常見錯誤（附真實錯誤訊息）

錯誤 1：忘了 return

static int add(int a, int b) {
    int sum = a + b;
}
AddDemo.java:4: error: missing return statement
    }
    ^

方法頭說會吐出 int，本體卻沒有 return。改法：最後加 return sum;。

錯誤 2：忘了 static

int add(int a, int b) { return a + b; }
...
System.out.println(add(3, 5));   // 在 main 裡
AddDemo.java:6: error: non-static method add(int,int) cannot be referenced from a static context
        System.out.println(add(3, 5));
                           ^

main 是 static，只能直接叫 static 方法。改法：方法頭加 static。

錯誤 3：回傳型態對不上

static int half(int x) {
    return x / 2.0;
}
AddDemo.java:3: error: incompatible types: possible lossy conversion from double to int
        return x / 2.0;
                 ^

x / 2.0 是小數（double），但方法說要吐 int。改法：回傳型態改成 double。

錯誤 4：把 void 方法的結果存起來

String s = greet("小明");
AddDemo.java:6: error: incompatible types: void cannot be converted to String
        String s = greet("小明");
                        ^

void 方法什麼都不吐，沒有東西可以存。改法：單獨寫 greet("小明");。

看錯誤訊息的順序：檔名 → 行號 → 英文關鍵字。

先跳到那一行，再對照上面四種：missing return、non-static、lossy conversion、void cannot be converted。

6. 練習

練習 1：System.out.println(add(add(1, 2), 3)); 會印出什麼？

6。先算裡面的 add(1, 2) 得 3，再算 add(3, 3) 得 6。方法的回傳值可以直接當成另一次呼叫的參數。

練習 2：寫一個 max 方法，傳入兩個整數，回傳比較大的那個。 
static int max(int a, int b) {
    if (a > b) {
        return a;
    }
    return b;
}

測試：max(4, 9) 印出 9，max(-2, -7) 印出 -2。第一個 return 執行到就離開方法，所以不用寫 else。

練習 3：下面哪一行會編譯錯誤？為什麼？
static void show(int n) { System.out.println(n); }
(A) show(5);　(B) int x = show(5);

(B)。show 是 void，不回傳任何東西，不能放在等號右邊。錯誤訊息會是 void cannot be converted to int。
